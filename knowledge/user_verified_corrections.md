# Designer-confirmed corrections

## Confirmed working distinction
- 钢网水幕 is **not** the same as 拉线水帘.
- A fine stainless-steel mesh should not be drawn as widely spaced metal cables.
- When only a water-curtain material is changed, preserve water-feature scale, overall geometry and camera angle unless instructed otherwise.
- For water-effect replacement, map every visually identifiable original outlet one-to-one by default. Preserve outlet count, base position, spacing, row alignment, sequence and density; do not omit, add, move or redistribute outlets without explicit approval.
- Before generation, explicitly confirm outlet mapping/density, direction or trajectory, water character (clear coherent/no-splash versus turbulent/aerated), continuity (continuous versus segmented/pulsed), height profile and lighting. Missing or ambiguous confirmation blocks generation.
- Catalogue reference images constrain water behaviour only and must not override the original project's outlet layout.
- Remove visible source logos and watermarks by default in generated visualisations; preserve them only if requested.
- Visual QA must audit outlet-level correspondence and identify missing, added or moved outlets and density changes, even when the requested water type is otherwise correct.

## Workflow
When another mismatch occurs, record: requested effect, incorrect output, approved correction, evidence/reference page, and whether it is a case-specific rule. Do not generalise an unverified correction across all manufacturers.
