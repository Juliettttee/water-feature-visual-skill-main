# Source catalogues (local only)

Place the original manufacturer PDF catalogues in this directory before rebuilding the local knowledge base.

Expected local sources include OASE Professional, Fontana and Crystal catalogues. The source PDFs are private/local reference material and are intentionally excluded from Git by the repository `.gitignore`. Do not commit or upload catalogue PDFs, extracted pages or derived image libraries.

将 OASE Professional、Fontana 和 Crystal 的原始目录 PDF 放在此文件夹中，再运行本地知识库构建脚本。原始 PDF 仅供本地参考，已被 `.gitignore` 排除，禁止提交或上传到 GitHub。
